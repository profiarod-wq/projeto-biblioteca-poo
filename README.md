# Biblioteca POO - Semana 07

Projeto didático para a UC Programação Orientada a Objetos.

## Objetivos da atividade
- Publicar um projeto no GitHub
- Conhecer repositório, commit e histórico
- Organizar tarefas no Trello
- Evoluir uma aplicação Java com MySQL
- Implementar uma nova funcionalidade durante a Sprint

## Projeto
Sistema de Biblioteca com:
- Java 21
- Maven
- JDBC
- MySQL
- Organização em camadas

## Segurança
A senha do MySQL NÃO deve ser enviada ao GitHub.

Copie:
`src/main/resources/config.properties.example`

Renomeie a cópia para:
`config.properties`

Depois informe sua senha local.

O arquivo `config.properties` está protegido pelo `.gitignore`.
